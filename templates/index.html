Explainable AI Image Uploader

This website is a work in progress. The vision is to allow users to submit an image, run inference with one of our models hosted on the server, and receive a prediction with a confidence score. Additionally, the site will generate and display an Integrated Gradients attribution matrix for the image to explain the model's decision. For now, you can submit an image below and the website will just convert it to grayscale, which demonstrates that we can at least process and return images.
